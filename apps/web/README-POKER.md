# Poker Tutor — Interactive Website Concept

Goal: interactive, high-aesthetic, fun site that teaches poker step-by-step (focus: Texas Hold’em).

## Principles
- Learn by playing micro-hands (30–90s each)
- Only introduce one new concept at a time
- Visual-first (chips, pot, betting rounds)
- Tooltips for every term (pot odds, kicker, position)

## Learning Path (Step-by-step)
1) Hand rankings (5 min)
2) Game flow: preflop → flop → turn → river
3) Betting actions: check/bet/call/raise/fold
4) Positions + why they matter
5) Reading the board: pairs, flush/straight draws
6) Basic strategy: tight/aggressive starter ranges
7) Pot odds & simple EV intuition
8) Common mistakes + quizzes

## Core Interactions
- **Hand Lab**: drag 2 hole cards + 5 board cards → instantly explains best 5-card hand + why
- **Street Simulator**: click through betting rounds with guided prompts
- **Decision Scenarios**: “You have A♠Q♠ on K♠7♦2♠, opponent bets 1/2 pot — what do you do?”
- **Spaced repetition**: daily 2-minute drills (identify best hand, spot draws)

## Aesthetic
- Dark felt table, subtle grain, neon accent
- Smooth chip animations, tasteful sound toggle

## MVP Deliverables
- Landing + module grid
- Hand rankings interactive
- Hand Lab (best-hand explainer)
- 10 guided scenarios
